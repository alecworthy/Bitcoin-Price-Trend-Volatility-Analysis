# Bitcoin Price Trend & Volatility Analysis

---

## 📌 Project Overview

This project analyses historical Bitcoin price data to identify long-term trends, volatility, and key market movements. Using structured spreadsheet analysis, the project focuses on understanding how Bitcoin prices evolve over time and how volatility impacts market behaviour.

The goal is to transform raw cryptocurrency price data into clear insights using spreadsheet-based analytical techniques and visual reporting.

---

## 📁 Dataset Overview

The dataset contains historical Bitcoin pricing data, including:

- Date
- Opening price
- Closing price
- Daily high and low prices
- Trading volume

The dataset supports time-series analysis and volatility exploration using spreadsheet tools.

---

# 📊 Key Questions Explored

- How has Bitcoin’s price trended over time?
- What periods show the highest price volatility?
- How do major market movements compare across different time frames?
- Are there identifiable patterns during periods of rapid growth or decline?

---

# 🧠 Skills & Tools Demonstrated

- Excel – structured data analysis and reporting
- VLOOKUP – data matching and enrichment
- Pivot Tables – aggregation and trend analysis
- Line Charts – time-series visualisation
- Spreadsheet Modelling – organising and analysing financial data

---

# 🔄 Project Workflow

1. Data cleaning and formatting in Excel
2. Data enrichment using lookup functions
3. Aggregation of price data using Pivot Tables
4. Visualisation of price trends and volatility
5. Interpretation of market movements and trends

---

# 📈 Summary of Insights

- Bitcoin exhibits significant price volatility, with sharp increases and corrections over short time periods.
- Long-term analysis shows clear growth cycles followed by consolidation phases.
- Periods of heightened volatility often align with major market events and sentiment shifts.
- Line-chart analysis highlights recurring patterns in rapid price acceleration and decline.
